# XPrism logo

| File | Use |
|---|---|
| `logo-light.svg` | Full logo for light backgrounds |
| `logo-dark.svg` | Full logo for dark backgrounds |
| `icon.svg`, `icon-1024.png` | The mark alone: avatars, favicons, app icons |
| `logo-*-src.svg` | Editable sources (wordmark as text, needs the Inter font) |

The mark is a glass prism holding an X drawn in the classic X11 manner,
one thick and one thin stroke, the thin one broken where they cross.
White light enters from the left and leaves as a spectrum: X11, split
into what each application is allowed to do.

The wordmark is set in [Inter](https://rsms.me/inter/) ExtraBold
(SIL Open Font License) and converted to outlines in the `logo-light`
and `logo-dark` files, so they render the same everywhere.

Colors: indigo `#4f46e5` → violet `#7c3aed` (the X), `#a5b4fc` →
`#8b5cf6` (prism edge), spectrum `#ef4444 #f97316 #eab308 #22c55e
#3b82f6 #8b5cf6`.
