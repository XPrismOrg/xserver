# Logo

| File | Use |
|---|---|
| `logo-light.svg`, `logo-dark.svg` | The name, for light and dark backgrounds. Used in the README. |
| `icon.svg`, `icon-1024.png` | The mark on a dark tile, for application icons, avatars and favicons. |
| `mark-light.svg`, `mark-dark.svg` | The mark without a background, for light and dark backgrounds. |
| `logo-*-src.svg` | Editable sources of the name, with live text. They need the Inter font. |

The mark is an X in the style of the X Window System logo, with one thick
and one thin stroke. The thin stroke is plain; the thick stroke is cut
into facets in the colours of the spectrum. In the name, the mark takes
the place of the letter X.

The lettering is Inter Display Black ([Inter](https://rsms.me/inter/),
SIL Open Font License), converted to outlines in `logo-light.svg` and
`logo-dark.svg` so that the files display the same everywhere.

Colours: `#ff3b3b`, `#ff8a00`, `#ffd400`, `#21d07a`, `#1e90ff` and
`#8a3ffc`, each in a light, base and dark shade. The icon background is
a gradient from `#161b3d` to `#05060f`.
