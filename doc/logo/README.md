# XPrism logo

| File | Use |
|---|---|
| `logo-light.svg` | Full logo for light backgrounds |
| `logo-dark.svg` | Full logo for dark backgrounds |
| `icon.svg`, `icon-1024.png` | App icon: the mark on a dark tile (avatars, favicons) |
| `mark-dark.svg`, `mark-light.svg` | The mark alone, for dark or light backgrounds |
| `logo-*-src.svg` | Editable sources (wordmark as text, needs the Inter font) |

The mark is the classic X11 X, one thick and one thin stroke, the thin
one broken where they cross, cut like a crystal prism. The thin stroke
is white light; the thick stroke is that light split into a spectrum,
in faceted bands. The rainbow is also meant the way it reads: XPrism
welcomes everyone who wants to build it and use it.

The wordmark is set in [Inter Display](https://rsms.me/inter/) Black
(SIL Open Font License), with the X in the spectrum gradient, and is
converted to outlines in the `logo-light` and `logo-dark` files so they
render the same everywhere.

Colors: spectrum `#ff3b3b #ff8a00 #ffd400 #21d07a #1e90ff #8a3ffc`, each
band in a light, base and dark facet; tile `#161b3d` → `#05060f`.
